# Credits and acknowledgments

## The original Virtual-On arcade game

SEGA and the original creators of *Virtual-On: Oratorio Tangram M.S.B.S. Ver. 5.66* created the game this project seeks to preserve. The original game, artwork, characters, sound and related intellectual property remain with their respective owners.

PROJECT OT: Virtual On Experience is an unofficial fan project. It is not affiliated with or endorsed by SEGA.

## Flycast and the runtime foundation

[Flycast](https://github.com/flyinghead/flycast), maintained by flyinghead and its contributors, supplies the emulator foundation. Its source also acknowledges the [reicast](https://github.com/skmp/reicast-emulator) foundation and other contributors.

[Flycast Lean VOOT](https://github.com/hyp36rmax/flycast-lean-voot) maintains the runtime source, modifications and engineering documentation for this project. The [corrected RC source delivery](https://github.com/hyp36rmax/flycast-lean-voot/releases/tag/source-v0.5.0-rc.1-corrected) contains both matching runtime variants, dependencies, build materials, notices and hosted protocol documentation. Anonymous recipient access and checksums are verified; see [Runtime Source & Licensing](README.md#runtime-source--licensing).
