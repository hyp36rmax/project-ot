# Pick Up & Play

Start with [Getting Started](getting-started.md), then set up your controller, display and audio. Choose Solo, Local VS or LAN VS when ready to play.

## Set up PROJECT OT

1. [Getting Started](getting-started.md): package availability, Microsoft prerequisites, game files and launch.
2. [Controllers](controllers.md): gamepads, arcade Twin-Sticks, player assignment and Test Controls.
3. [Display](display.md): aspect ratio, rendering quality and single or dual displays.
4. [Audio](audio.md): output preferences, volume, mute and speaker tests.
5. [Gameplay](gameplay.md): the Arcade Cabinet Mode settings interface.

## Choose how to play

Use the [Multiplayer menu](multiplayer.md) for Local VS and [Link Play](link-play.md) for the LAN VS menu. NETPLAY VS remains unavailable.

[Solo](solo.md) runs the original arcade game for one player. [Local VS](local-vs.md) brings two independent players together on one PC, using one monitor or two physical displays. It also explains Arcade Cabinet Mode for dedicated setups. [LAN VS](lan-vs.md) connects stations over Ethernet or Wi-Fi.

Each guide explains how to start and leave a session. If something goes wrong, use [Troubleshooting](troubleshooting.md) and [Known Issues](known-issues.md). The [public RC](https://github.com/hyp36rmax/project-ot/releases/tag/v0.5.0-rc.1) and [matching runtime source](../README.md#runtime-source--licensing) are available. Follow the [release guide](release-guide.md) for layout and remaining qualification and licensing limits.

[Validation history](validation-history.md) records completed physical Solo, Local VS and LAN VS testing, controller/display acceptance and seven different LAN-discovery setups. It separates those development results from specific checks not repeated on the final corrected RC.
