# Feedback and diagnostics

Press **F12** at Title, Settings or gameplay. The RC opens **Feedback & Diagnostics**, not the DEV internal UAT checklist.

## Record what happened

Select the activity context, then **Working**, **Issue Found** or **Not Tested**. Details and tester alias are optional. Include the smallest repeatable sequence, controller setup, display aspect and rendering quality when relevant.

**Export Report + Diagnostics** saves locally. The export includes build/session context, module metadata and bounded recorded events. Review it before sharing; nothing is uploaded automatically. **ESC** closes the form and restores its prior context.

## Automatic collection and privacy

Normal application events continue recording automatically. The verbose DEV spool and automatic package export remain DEV-only under the existing channel policy. RC uses normal event logging and local feedback export. Never attach game archives, BIOS files, saves or personal information to an issue.

See [Troubleshooting](troubleshooting.md#reporting-a-problem) and [Known Issues](known-issues.md).
