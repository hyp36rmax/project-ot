# Local VS: two players on one PC

Local VS brings original linked-cabinet competition to one Windows PC. Each player has independent controls and a separate game view. PROJECT OT manages the cabinet link and ends both local views together.

## Set up a match

1. Open **Settings → Controllers** and [assign a different device](controllers.md) to each player.
2. Test both players. One player's inputs should not activate the other's contacts.
3. Choose **Single Display** or **Dual Display VS** in [Display](display.md).
4. Review [Audio](audio.md) for common or player-specific preferences and its live-routing limit.
5. Return to Title and choose **Multiplayer → Local VS**. Follow the original game prompts on both views.

Compatible gamepads and Twin-Sticks can be mixed. P1 can use keyboard fallback; P2 needs a physical controller.

Single Display puts both independent views on one monitor. Dual Display VS gives each player a separate physical display. Assign monitors before starting.

## Arcade Cabinet Mode

Arcade Cabinet Mode is a validated feature for dedicated setups, with two persistent NAOMI cabinet environments and independent player controls and displays. Select the same-PC Local VS session in Display settings and use its **Arcade Cabinet Mode** choice. This is distinct from a standard temporary Local VS session.

## Resume or finish

The Experience menu does not guarantee synchronized pause; linked gameplay can continue. Use Resume to return, or confirm Return to Title to end the paired session. Wait for Title before starting another mode, then confirm Exit when finished.

See [Known Issues](known-issues.md) for configuration-specific limits.
