# Project OT v0.5.0-rc.1

[v0.5.0-rc.1 is available as a public Release Candidate](https://github.com/hyp36rmax/project-ot/releases/tag/v0.5.0-rc.1). Matching corrected native-runtime source is public; Experience source-scope and installation obligations remain unresolved.

[Full candidate release notes](../RELEASE-NOTES-v0.5.0-rc.1.md) include feature scope, installation, feedback and the remaining qualification and licensing limits.

## What is in the candidate

- The established Title, Pause, Settings and Multiplayer presentation.
- Simplified F12 Feedback & Diagnostics in RC, with local export and automatic build/session context.
- Hidden Settings module-version labels while retaining the main application version and diagnostic metadata.
- Matching Automatic and explicit Local VS Single Display geometry: 4:3, 16:9 and 21:9 stacked; 32:9 side by side.
- The approved Solo launch correction that enables widescreen rendering for saved 16:9, 21:9 and 32:9 selections. First-frame physical retesting was not performed.
- The unchanged qualified Solo/Local and LAN runtime executables, integrity checks and coordinated process lifecycle.
- Framework-dependent Windows x64 layout with a root data directory and no supplied game or BIOS archives.

Original gameplay, renderer, controller routing and LAN transport are unchanged. No performance improvement is claimed.

## Install

Read [Getting Started](getting-started.md) and [the package guide](release-guide.md). Use official external .NET 10 Runtime x64 and Visual C++ v14 x64 prerequisites. Supply your own compatible game and firmware.

## Known issues and approval

Sustained LAN and the reported 0xB002 remain unresolved. Remaining impact-flash, Windows-dialog and physical RC checks are open. The earlier Solo-to-Title navigation report was not reproduced on physical retest. Native-runtime source delivery and anonymous recipient access are verified; additional Experience source-scope, installation obligations and proposed recipient terms remain under review. No full compliance clearance is claimed.
